# Support

Use GitHub Issues for reproducible bugs and feature requests. General Starsector gameplay questions are better suited to the official Starsector community.

For support requests, provide:

- Consumption Control version;
- Starsector and LunaLib versions;
- active mod list;
- configured multipliers;
- relevant `starsector.log` lines;
- whether the issue reproduces on a new or copied save.

Always back up saves before testing development builds.
